Import the D'Tunes Status video

Source package: status-video.tgz. Final file: dtunes_status_feature_video_v7.mp4 (30.09s, 1080x1920).

1. Save the source in the D-Tunes repo

git clone https://github.com/Dcode9/D-Tunes.git && cd D-Tunes
git checkout -b add/status-video-source
mkdir -p tools && tar xzf /path/to/status-video.tgz -C tools
git add tools/status-video
git commit -m "Add D'Tunes Status feature video source"
git push -u origin add/status-video-source

Open a pull request from that branch. Do not push to main. Nothing is in the repo until you do this.

2. Rebuild the video

You need Google Chrome, Python 3 with numpy and Pillow, and ffmpeg. The soundtrack MP3 is not in the package. Use the same file: audio-3ae9e05b.mp3 (54.12s).

cd tools/status-video
./build.sh /path/to/audio-3ae9e05b.mp3 dtunes_status.mp4

It takes about 3 minutes. The script makes the text layers, the 110 sweep frames for the ending, all 722 video frames, and the audio (first 30.09s, fade out 23.09 to 30.09), then joins them.

3. Check it matches

On Chrome 156, ffmpeg 4.4.2, Pillow 12.3, numpy 2.2 the rebuild is byte-identical to the delivered file. SHA-256 of the delivered file:

9892f39bcd6c121ef85f5a5c7cc626d1928188d49b1b1adfb7d00bec6c7d532b

Other versions can differ by a few pixels or bytes. If so, compare it by eye with the delivered video, especially the end.

4. Post it as a WhatsApp Status

  1. Move the MP4 to your phone.
  2. WhatsApp, Updates tab, add a status, pick the video from the gallery.
  3. Send it to your contacts. The video has no sound effects, only the soundtrack.

Change something

  • Headline text: edit t1.html to t5.html (the intro is t0.html, the Get D'Tunes card is t6.html).
  • Timing and motion: the top of render_video.py holds the scene start times and lengths.
  • Ending: beam.html. Open it with ?t=25.6 to see one moment. It is the old D-UI sweep beam.
Vibe Mix and offline are tagged "Windows & web" in the video because they are not confirmed on Android. Change that only after the Android build is checked.

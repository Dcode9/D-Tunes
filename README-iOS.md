# D-Tunes iOS (Aave Glass + Web Haptics)

Branch: `ios-aave-glass-haptics-v2`

Complete working app based on main, with:

- **Aave Glass** visual language applied to glass panels, player, nav, song pills (specular + depth)
- **Web Haptics by Lochie** patterns for tactile feedback on mobile

Load `src/ios-enhancements.js` (add the script tag before `</body>` in index.html if not present).

Production / main stays unchanged. This branch is the iOS-optimized experience.

Live preview will appear after Vercel builds the branch.
